# Overview:
This project detects the language of a given text using Natural Language Processing (NLP) techniques and a Multinomial Naive Bayes model.
It identifies the language from text input and displays the result accurately.
## Key Features:
Preprocessing and cleaning of text
Bag-of-Words model using CountVectorizer
Classification using Multinomial Naive Bayes
Evaluation using accuracy score and confusion matrix
Function to predict language of any new input text
## Technologies Used:
Python
Pandas
NumPy
Scikit-learn
Matplotlib
Seaborn
Regex (re)
